# Interview Quiz ⚡

## General Overview 🌐

Interview training app that features questions filtered by specialization, skills, difficulty, and rating

## Key Features 🗝️

- Retrieving and listing questions from API
- Pagination
- Filtering questions by available parameters
- Keyword search
- Navigating to a specific question page on click
- Displaying detailed question

## Available Scripts 📑

### Via **Bun**

```sh
bun run dev                # Start the development server
bun run build              # Build the production-ready app
bun run lint               # Run linter check
bun run lint:fix           # Run linter fix
bun run format             # Run formatter check
bun run typecheck          # Run TypeScript type check
bun run prepare            # Setup Husky hooks
```

### Via **npm**

```sh
npm run dev                # Start the development server
npm run build              # Build the production-ready app
npm run lint               # Run linter check
npm run lint:fix           # Run linter fix
npm run format             # Run formatter check
npm run typecheck          # Run TypeScript type check
npm run prepare            # Setup Husky hooks
```
